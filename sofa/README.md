# Sofa - Mathematical Visualizations

## Requirements

- Java 8+

## Function Plotter

```bash
javac Funktionsplotter.java && java Funktionsplotter
```

## Fibonacci Sunflower

```bash
javac FibonacciSunflower.java && java FibonacciSunflower
```

## Fibonacci Galaxy

```bash
javac FibonacciGalaxy.java && java FibonacciGalaxy
```

## Fibonacci Tree

```bash
javac FibonacciTree.java && java FibonacciTree
```

## Taylor Series - e^x

```bash
javac TaylorExponential.java && java TaylorExponential
```

## Math Explorer

```bash
javac MathExplorer.java && java MathExplorer
```
