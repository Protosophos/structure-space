# Sofa - Mathematical Visualizations

## Requirements

- Java 8+

## Function Plotter

```bash
javac Funktionsplotter.java && java Funktionsplotter
```

## Fibonacci Sunflower

```bash
javac FibonacciSunflower.java && java FibonacciSunflower
```

## Fibonacci Galaxy

```bash
javac FibonacciGalaxy.java && java FibonacciGalaxy
```

## Fibonacci Tree

```bash
javac FibonacciTree.java && java FibonacciTree
```
